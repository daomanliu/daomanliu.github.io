# 2026-08-06

## Markdown 笔记本 → 个人博客改造（daomanliu.github.io）

用户要求把 Vue3 笔记本项目改造成个人博客：无多用户、仅站长一个登录、文章以 md 放在 index.html 同目录、部署到 GitHub Pages（daomanliu.github.io）。

关键决策与结构：
- `src/config/blog.js`：博客信息 + 站长账号（用户名 + 密码 SHA-256 哈希，默认密码 123456）
- `public/posts/*.md`：文章（front-matter: title/date/tags/summary），构建后落到 `dist/posts/`（与 index.html 同级）
- `scripts/build-posts-index.js`：扫描 posts 生成 posts.json，挂到 predev/prebuild（`npm run posts` 可单独跑）
- 路由（hash 模式）：`/` 首页、`/post/:slug` 文章页（公开）、`/login`、`/admin`（需登录，守卫）
- `stores/posts.js`：运行时 fetch posts.json + md；后台编辑先存 localStorage 覆盖层（blog-post-overrides / blog-post-drafts），导出 md 后需放回 public/posts 重新构建才真正发布
- 文章正文样式抽为全局 `src/assets/markdown.css`（.markdown-body）
- vite base 为 `/`（用户主页仓库）；旧文件已删：NoteLayout/EditorView/NoteList/stores/notes.js
- 构建验证通过，preview 下 /、/posts/posts.json、/posts/*.md 均 200
