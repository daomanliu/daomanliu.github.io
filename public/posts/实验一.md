# 实验一·基础Web程序
> 1. 打开[脚手架构建工具](https://start.spring.io/)，按如下选择填写，然后generate，把下载下来的压缩包里面的文件夹复制到项目目录里，用IDEA打开这个文件夹，加载maven项目
> 2. 在路径`src/main/java/com/example/demo`下创建`controller`文件夹，新建类`Hello`。
> 3. 在类名上面加注解`@RestController`，在类里面写一个简单的函数如下
```
public String hello(){
        return "Hello World!";
    }
```
> 然后加上`@GetMapping("/hello")`注解
> 4. 运行应用，在 http://localhost:8080/hello 里就能看见`Hello World!`了
