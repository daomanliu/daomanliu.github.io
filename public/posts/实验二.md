> 1. 在`src/main/java/com/example/demo`下创建`dto`包，创建两个类`LoginRequestDTO`和`LoginResponseDTO`
> 2. 在`pom.xml`里加一个`lombok`依赖，代码如下，然后同步maven
```
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <optional>true</optional>
    <scope>provided</scope>
</dependency>
```

**也可以在建脚手架的时候把lombok加上，就不用写这个配置**

> 3. 在`LoginRequestDTO`类名上写`@Date`，`@AllArgsConstructor`，`@NoArgsConstructor`注解，类里写两个属性`private String username`和`private String password`；在`LoginResponseDTO`类名上写`@Date`，`@AllArgsConstructor`，`@NoArgsConstructor`注解，类里写三个属性`private boolean success`，`private String message`，`private String username`
> 4. 在`controller`包里创建`LoginController`类，用来写业务逻辑
> 和之前的`Hello`一样，在类名上面加`@RestController`注解，在类里面写如下函数
```
@RestController
public class LoginController {
    @PostMapping("/login")
    public LoginResponseDTO login(@RequestBody LoginRequestDTO loginRequest) {
        if ("admin".equals(loginRequest.getUsername()) && "admin".equals(loginRequest.getPassword())) {
            return new LoginResponseDTO(true, "登陆成功", loginRequest.getUsername());
        } else {
            return new LoginResponseDTO(false, "账号或密码错误", null);
        }
    }
}
```
> 5. 把现在服务端的三个类`LoginController`，`LoginRequsetDTO`，`LoginResponseDTO`交给AI，用提示词`“根据现在的服务端设计，创建一个登录页面，来模拟登录功能。”`，让AI写一个前端登录页面。把AI生成的前端页面放在文件夹`resources/static`里面，命名为`login.html`
> 6. 启动应用，启动注解处理，用`F12`打开开发者工具的网络，观察登录情况
